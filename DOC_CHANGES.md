# Documentation change log — 2026-10-23

This log covers every file changed since the initial commit `a7582a3`. See `git diff a7582a3` for the exact text.

Each change is tagged with one of three types:

- **NUM** — a hard number was wrong.
- **CMD** — an execution command, flag, path or default was wrong.
- **LOGIC** — the docs described a mechanism, formula, rule or status that the code doesn't implement.

Rules applied throughout:

- Every new figure comes from a code constant, a committed CSV/JSON, or a read-only computation on `input datasets/*.parquet`.
- Reports that record past runs keep their recorded numbers. Where a report is stale, it gets a dated note ("Note (2026-10-23): …") instead of rewritten figures.
- Obsidian-Notes/ and Strategy-In-Progress/ were reviewed and then **reverted at your request**, so they are unchanged.
- Scenario-card *templates* were skipped as requested. The two card `.md` files still carry the small first-pass edits listed in §7.

Totals: 63 files, of which 13 are `.py` files where only documentation-producing code was changed.
