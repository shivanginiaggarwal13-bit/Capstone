# MEIO Weekly — Statistical CSL Backtest
Supply Brain capstone | generated by `backtest_csl.py`

> **Note (2026-10-23):** this run predates the 2026-10-18 change to
> `meio_weekly_lib.assign_z()`. It sized z off `sku_master.csv`'s segment
> (`Z_BY_SEGMENT`: Fast-Moving 2.05, Seasonal 1.64, Intermediate 1.28), which
> is what the ~95.5% average target CSL below reflects. The current code takes
> z from the canonical segmentation output
> (`output datasets/segmentation/sku_clusters.csv`, currently v5), so a re-run
> of `backtest_csl.py` would produce different target and achieved CSLs. The
> numbers below are the recorded run, unchanged. Scope: `backtest_csl.py`
> checks RDC/CDC reorder points from `solve_policy()` only; PDC rows are not
> built or checked. The demand estimate also blends in the de-seasonalized
> level (`MEAN_BLEND_ALPHA=0.6`), not only the bias correction and blended CV.

## Window
As-of weeks 2025-W14 .. 2025-W48 (35 weeks), no lookahead:
every reorder point checked here was computed from data at or before its
as-of week only, using the same estimation functions
(`meio_weekly_lib.target_week_demand`, bias-corrected, blended-CV) the live
weekly optimizer uses.

## Result
- **Achieved portfolio CSL: 97.6%** vs average target 95.5%
  across 248,850 checkable (sku, dc, as-of-week) lines.
- Lead-time-demand window = lt_mean_wk weeks from the target week, with the
  final partial week weighted by its fraction (uniform-within-week
  approximation, since demand data is weekly grain); rows whose window
  runs past the last available in_sample week are excluded, not penalized.
